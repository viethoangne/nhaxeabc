# Mobile App (Nha xe ABC)

Ung dung mobile dat ve cho khach hang, dung chung backend va database voi he thong web admin.

## Muc tieu kien truc

- Mobile va web la 2 client cua cung 1 he thong.
- Business logic nam o backend; mobile chi xu ly presentation + UX.
- Du lieu dat ve, loyalty, tra cuu, thanh toan phai dong bo theo API backend.

Tai lieu trien khai chi tiet: `mobile/WEB_MOBILE_UNIFIED_SYSTEM_PLAN.md`.

## Chay du an

1. Cai dependency

```bash
npm install
```

2. Cau hinh bien moi truong Expo (`EXPO_PUBLIC_API_BASE_URL`, `EXPO_PUBLIC_WEB_URL`)

3. Chay app

```bash
npx expo start
```
